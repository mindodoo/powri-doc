## What Went Well

1. **Read path first (12.1) unblocked write and moderation cleanly.** Public GET, SSR aggregate, and `web/src/lib/reviews/` modules with paired tests meant 12.2 and 12.4 extended small surfaces instead of rewriting the list.
2. **Auth reuse from Epic 9.** `openSignIn({ trigger: 'review' | 'report' })`, session clients, and `createAdminClient()` for moderation writes matched architecture §4.6 without inventing a second admin channel.
3. **PO-deferred 12.3 mid-epic, then 12.4 stayed reviews-only.** Shard, PRD, and `deferred-work.md` were updated in the same decision window — next agents are not left guessing about `CommentList` / `/api/comments`.
4. **Storage adapter + pin-provider-at-upload (12.2.1 review).** Echoing `storageProvider` from issue → confirm prevents env flip mid-request. Dual-read URLs by `storage_provider` column keep legacy Supabase rows visible.
5. **Review findings were patched in-story, not parked.** 12.2.1 two review rounds and 12.4 hide/unhide status guards (no resurrecting `deleted`; no author republish of admin-hidden) landed before `done`.
6. **UGC sanitize + rate-limit landed with writes (12.2).** `lib/ugc/sanitize.ts` and `ugcWrite` limiter exist before public launch — NFR-10/12 not left as a 15.4 surprise.
7. **Mobile/desktop form split was specified up front (12.2 PO).** Full-screen page vs modal avoided the Epic 11-style “one responsive AC” trap for a heavy form.
8. **Background photo queue as module-level pub/sub.** Survives mobile navigate-away after text save; `ReviewList` subscribes for “uploading” + refetch. Honest v1 limitation documented (tab close drops in-flight uploads).

## Challenges & Growth Areas

1. **Infra story (12.2.1) generated the densest review surface of the epic.** Silent R2→Supabase fallback, public URL vs S3 endpoint mix-up, migration pagination, and unbounded presigned PUT size all appeared in review — several would have been silent production failures.
2. **Photo pipeline complexity stacked across 12.2 then 12.2.1.** 12.2 added `sharp` + 20 MB input cap + background upload; 12.2.1 then forced always-WebP + R2. Confirm-route error handling and provider pinning had to be rediscovered rather than designed once.
3. **Dev-server i18n staleness (12.4 QA).** New `en.json` keys rendered as literal paths until Turbopack restart (`MISSING_MESSAGE`). Production builds are fine; local QA needs a restart after message-file edits.
4. **Admin write path vs RLS.** No `is_admin()` write policy on `reviews`; hide/unhide correctly use service role after `requireAdmin()`. Easy to “fix” the wrong layer if the next story adds admin UI without reading 12.4 notes.
5. **Manual QA / Playwright gap on moderation.** 12.4 story explicitly flags live hide → list disappearance and guest-report → sign-in as unrun in the implementing session. Migration `009_moderation_admin_visibility.sql` must be applied before admin hidden-row visibility works.
6. **Architecture doc lag.** Phase 2 architecture still lists **Supabase Storage** as the photo store; R2 is production intent. Comments APIs remain in the architecture table though 12.3 is deferred.
7. **Guest report does not resume into `ReportReviewDialog` after auth** (deferred). Matches AC6 as written (`SignInSheet` + `returnTo`) but is a worse UX than 12.2’s post-sign-in auto-open form.
8. **Orphaned unconfirmed uploads** have no lifecycle rule in either storage provider — carried from 12.2 into 12.2.1; still open in `deferred-work.md`.

## Key Insights

1. **Pin the storage provider at issue time; never re-resolve at confirm.** Env or flag changes between the two requests otherwise write metadata for the wrong backend.
2. **Public photo URLs must go through the validated R2 base-URL helper.** Reading `R2_PUBLIC_BASE_URL` raw can point `<img>` at the private S3 endpoint; one bad row must not throw the whole review list `.map()`.
3. **Treat R2 HeadObject/download failures as infra errors, not “not found.”** Blanket catch turns credential mistakes into “not yet migrated.”
4. **Admin hide is not owner delete.** `hidden` vs `deleted` must stay distinct: hide/unhide 404 on deleted; author POST must 409 on hidden (do not republish around moderation).
5. **Service-role writes + session `requireAdmin()` is the Phase 2 admin pattern.** Do not add `is_admin()` UPDATE policies unless architecture changes.
6. **Defer comments as a product cut, not a “later in this epic” leftover.** 12.4 would have grown a second content type without the 2026-08-13 PO block.
7. **`next-intl` dynamic `import()` of `en.json` does not hot-refresh an already-open tab.** Restart the dev server after adding message keys before calling it a product bug.
8. **Optimistic local card state must remount-sync from list refetch** (`ReviewCard` status vs `ReviewList` key) or hide/unhide and list refresh drift.
